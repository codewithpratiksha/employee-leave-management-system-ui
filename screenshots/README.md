# Employee Leave Management System

Employee Leave Management System UI is a responsive frontend application designed to simplify leave management for employees and administrators.

## Features

Employee Module

* Employee Registration Page
* Employee Login Page
* Employee Dashboard
* Apply Leave Form
* View Previous Leave Requests
* Responsive Design

Admin Module

* Admin Login Page
* Admin Dashboard
* View All Employee Leave Requests
* Approve Leave Requests
* Reject Leave Requests
* Responsive Design

## Technologies Used

* HTML5
* CSS3
* Bootstrap 5
